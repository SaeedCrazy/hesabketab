# تصمیم‌های محصول (ثبت‌شده با صاحب محصول)

| موضوع | تصمیم |
|---|---|
| نوع محصول | پلتفرم حسابداری/ERP عمومی و کامل برای همهٔ صنف‌ها و همهٔ اندازه‌ها (کوچک تا بزرگ)؛ مخصوص یک صنف نیست |
| مشتریان اولیه (فقط مثال) | کافه، کفش‌فروشی، فروشگاه کالای برق |
| مدل فروش | هر دو: سرویس آنلاین چندمشتری (SaaS) + نصب روی سرور مشتری (On-prem) |
| سمت سرور | Python (FastAPI) + PostgreSQL |
| ظاهر برنامه | Vue 3 |
| دستگاه‌ها | وب و موبایل (PWA)، صندوق آفلاین، اپ ویندوز، اپ اندروید |
| انتقال داده از نرم‌افزار قبلی | هلو، سپیدار، محک، حسابفا، اکسل، و سایر نرم‌افزارهای حسابداری |
| میزبانی | سرور ایران، بدون وابستگی به سرویس‌های خارجی |
| پنل مدیریت | پنل کامل برای صاحب پلتفرم |
| کیفیت | تست خودکار گسترده برای اطمینان از درستی |

## دور دوم تصمیم‌ها (پس از پژوهش‌ها، ۲۶ آبان ۱۴۰۵)

| موضوع | تصمیم |
|---|---|
| صنف‌های کامل در نسخهٔ ۱ | کافه و رستوران، کفش و پوشاک، کالای برق، و کسب‌وکار عمومی کوچک و متوسط. معماری از روز اول برای همهٔ صنف‌ها آماده است و صنف‌های دیگر (تولیدی، پخش، پیمانکاری، ...) بعداً به‌شکل «بستهٔ صنفی» اضافه می‌شوند |
| سرور نسخهٔ نصبی (On-prem) | در نسخهٔ ۱ فقط لینوکس (بستهٔ Docker). Windows Server در صورت نیاز بعداً |
| کلید امضای سامانهٔ مؤدیان در نسخهٔ آنلاین | انتخاب با مشتری: پیش‌فرض روی سرور ما با رمزنگاری لایه‌ای و قرارداد مسئولیت؛ مشتری حساس می‌تواند کلید را روی دستگاه خودش نگه دارد |
| حقوق و دستمزد در نسخهٔ ۱ | کارکنان مشمول قانون کار + ساعتی و پاره‌وقت؛ فیش، بیمه و مالیات حقوق؛ تولید فایل لیست بیمه و مالیات برای بارگذاری دستی |
| شبکهٔ نمایندگی | مدل داده در نسخهٔ ۱؛ پرتال کامل نمایندگان (کمیسیون، فروش، تسویه) در اولین به‌روزرسانی پس از عرضه |
| دستیار هوشمند (AI) | در محصول باشد. صاحب محصول از API استفاده می‌کند؛ پس ارائه‌دهندهٔ مدل باید قابل تنظیم باشد (API سازگار با OpenAI، سرویس‌دهندهٔ داخلی یا مدل خودمیزبان). دستیار اختیاری است و خاموش یا قطع بودنش هیچ اثری بر حسابداری ندارد. عملیات مالی را فقط پیشنهاد می‌دهد و کاربر تأیید می‌کند |
| نرم‌افزار مبدأ مشتریان اول | همه: هلو، سپیدار، حسابفا، اکسل و دفتر دستی، و سایر نرم‌افزارها. ابزار انتقال هلو، سپیدار، حسابفا و اکسل در نسخهٔ ۱ |
| دادهٔ نمونه برای آزمون انتقال | صاحب محصول با رضایت کتبی مشتریان بکاپ یا خروجی Excel تهیه می‌کند |
